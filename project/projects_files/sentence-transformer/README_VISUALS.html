2. Create Architecture Diagrams

High Priority: These are essential for understanding the model.

Option A - Automatic (Recommended):

# Install torchviz
pip install torchviz graphviz

# In your notebook or script
from torchviz import make_dot
import torch

# Create dummy input
dummy_input_ids = torch.randint(0, 1000, (1, 10))
dummy_attention_mask = torch.ones(1, 10)

# Forward pass
class_logits, ner_logits = model(dummy_input_ids, dummy_attention_mask)

# Visualize
dot = make_dot(class_logits, params=dict(model.named_parameters()))
dot.render('assets/architecture_diagram', format='png')

Option B - Manual: - Use draw.io or diagrams.net - Create boxes for: Input → Transformer → CLS Token / All Tokens → Classification Head / NER Head → Outputs - Export as PNG at 300 DPI

4. Generate Training Curves

If you have training history, use the helper script:

from generate_visuals import generate_training_curves

# Assuming you saved losses during training
generate_training_curves(
    train_class_losses=[0.5, 0.4, 0.3, 0.25, 0.2],
    val_class_losses=[0.55, 0.45, 0.35, 0.3, 0.25],
    train_ner_losses=[0.6, 0.5, 0.4, 0.35, 0.3],
    val_ner_losses=[0.65, 0.55, 0.45, 0.4, 0.35]
)

If you haven’t trained yet, you can create example curves or wait until after training.

Tips

  1. Consistency: Use the same color scheme across all visuals
  2. Quality: Save at 300 DPI for publication quality
  3. Accessibility: Ensure text is readable (12pt minimum)
  4. Dark Mode: Consider if your site has dark mode - test both
  5. File Size: Optimize PNGs for web (use tools like optipng or pngquant)
